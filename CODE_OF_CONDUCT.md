# Community code of conduct

We want contributors of different backgrounds and experience levels to work
productively together. Treat people with respect, assume good intent when possible,
and discuss code and decisions with specific evidence. Make room for questions,
acknowledge mistakes and give actionable feedback.

Harassment, discriminatory abuse, threats, sexualized behavior, sharing private
information without consent, and repeated disruptive conduct are not acceptable.
These expectations apply to repository discussions, issues, pull requests and
other spaces explicitly maintained for this project.

Report conduct concerns privately to a repository maintainer using a private
contact channel listed on their public profile. Do not publish personal details
or sensitive evidence in an issue. Maintainers should acknowledge reports,
consider the context and protect reporter privacy as far as reasonably possible.
If a report concerns a maintainer, contact another listed maintainer when available.

Responses may include a request to change behavior, removal of content, a warning,
a temporary participation restriction or a ban. Decisions should be proportionate
to impact and repeated behavior. A participant may request reconsideration
privately and provide additional context. Retaliation for a good-faith report is
unacceptable.

This is an original project policy, distributed under the repository's MIT license.
It does not imply the existence of a separate moderation team.
